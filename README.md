# NLP Analysis of ICT Job Market Trends

This project applies natural language processing (NLP) techniques to analyze over 4,400 job descriptions across ICT-related roles.

## Objectives
- Identify technical and soft skills most frequently demanded in ICT hiring
- Compare hiring-language patterns across occupations
- Extract employer preference trends using text mining methods

## Methods
- Text preprocessing & lemmatization
- TF-IDF analysis
- Bigram extraction
- POS / noun-chunk analysis
- LDA topic modeling
- Logistic Regression / Naive Bayes classification

## Tools
Python, Pandas, Scikit-learn, SpaCy, Matplotlib

## Key Findings
- Communication and teamwork frequently co-occur with technical skill requirements
- Data, systems, security, and development are among the most distinctive ICT keywords
- Topic modeling identified clusters related to auditing, marketing, accounting, and technical operations
